# Python Automation Scripts

This repository contains Python scripts for automating common system tasks.

## Features
- Log rotation
- File & directory backup
- System resource monitoring (CPU, Memory, Disk)

## Tech Stack
- Python 3
- psutil
- shutil
- cron (for scheduling)

## How to Run
pip install -r requirements.txt
python scripts/system_monitor.py

## Use Case
These scripts can be scheduled using cron for basic DevOps automation.
